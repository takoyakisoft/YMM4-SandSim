YMM4-SandSim
============

ゆっくりMovieMaker4用のGPUサンドシミュレーション映像エフェクトです。
映像や画像の色と透明度を保ったまま、砂、液体、気体、固体としてシミュレーションできます。
57種類の物理素材を扱い、固定素材の変形と破断、爆発からの着火と延焼、発光と影にも対応しています。

インストール
------------

同梱の YMM4SandSim-*.ymme をダブルクリックし、YMM4の案内に従ってインストールしてください。

手動で導入する場合は、プラグイン一式を YMM4 の user\plugin\YMM4SandSim フォルダーへ配置してください。

問題が発生した場合は、プラグインフォルダー内の YMM4SandSim.log を確認してください。

動作環境
--------

- Windows 10 / 11（64 bit）
- .NET 10対応版のゆっくりMovieMaker4
- DirectX 11対応GPU
